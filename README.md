# Stylito - Fashion App

A modern, responsive e-commerce fashion application and web experience built with Flutter and GetX.

## Features
- **Modern UI/UX**: Clean onboarding, product showcases, deal banners, and stylish catalog.
- **Interactive Shopping**: Dynamic cart, wishlist, categories, and checkout process.
- **Multi-Factor Authentication**: Local & secure phone OTP and Google sign-in workflows.
- **REST Backend Ready**: Fully integrated with backend server.

## Getting Started
1. Run `flutter pub get`
2. Start the app: `flutter run`
