# Stylito - Fashion & Lifestyle E-Commerce Application

A modern, responsive e-commerce mobile application and web experience built with Flutter, GetX, and Hive database.

## Features
- **Modern UI/UX**: Clean onboarding, product showcases, deal banners, and catalog.
- **Local NoSQL Database**: Powered by Hive for ultra-fast, offline-ready local storage.
- **Multi-Factor Authentication**: Local & secure phone OTP and Google sign-in workflows.
- **Interactive Shopping**: Dynamic cart, wishlist, categories, and checkout process.
- **REST Backend Ready**: Fully integrated with Express & SQLite backend server.

## Getting Started
1. Run `flutter pub get`
2. Start the app: `flutter run`
